## English

This repository contains a high-fidelity Chinese translation of the book **"Basic Read-Write Channels" (Volume I)**. The translation focuses on preserving technical accuracy, especially for mathematical equations and domain-specific terminology related to hard disk drive (HDD) signal processing.

### Table of Contents

- [Chapter 1: Basics of Magnetic Recording](chinese_final/chapter_1.md)
- [Chapter 2: Mathematical Foundations for Hard Disk Drives](chinese_final/chapter_2.md)
- [Chapter 3: Signal Transformations](chinese_final/chapter_3.md)
- [Chapter 4: Signals and Random Processes](chinese_final/chapter_4.md)
- [Chapter 5: Fundamental Communication Principles](chinese_final/chapter_5.md)
- [Chapter 6: Read and Write Processes in Hard Disk Drives](chinese_final/chapter_6.md)
- [Appendices](chinese_final/appendices.md)

### Repository Structure

- `thai_final/`: Original extracted Thai Markdown files.
- `chinese_final/`: High-fidelity Chinese translations, split by chapter.
- `.omo/`: Internal project tracking and metadata.
